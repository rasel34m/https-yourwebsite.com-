HTML কোডের গঠন
<!DOCTYPE html> ← ডকুমেন্ট টাইপ ঘোষণা
<html> ← পুরো পেজকে ঘিরে রাখে
  <head> ← শিরোনাম ও মেটা তথ্য
    <title>আমার প্রথম ওয়েব পেজ</title>
  </head>
  <body> ← আসল কনটেন্ট
    <h1>হ্যালো, বিশ্ব!</h1>
    <p>এটি আমার প্রথম HTML পেজ।</p>
  </body>
</html> ← শেষ ট্যাগ

জমা দিন
Form ট্যাগের ব্যাখ্যা
<form> → পুরো ফর্মকে ঘিরে রাখে

action → কোথায় ডাটা যাবে (যেমন অন্য পেজ বা সার্ভার)

method="post" → ডাটা পাঠানোর পদ্ধতি

<input> → বিভিন্ন ধরনের ইনপুট ফিল্ড

<label> → ইনপুট ফিল্ডের নাম/বর্ণনা

CSS দিয়ে সাজানো ওয়েবপেজ
এটি একটি সাধারণ ওয়েবপেজ।

এই লাইনটি হাইলাইট করা হয়েছে!

onclick="showMessage()" → বাটনে ক্লিক করলে showMessage() ফাংশন চালু হবে

alert("...") → একটি পপ-আপ মেসেজ দেখাবে
